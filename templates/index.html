Các Lớp Phòng Thủ Chính

Chống SQL Injection

Ngăn chặn kẻ tấn công chèn các câu lệnh SQL độc hại để thao túng cơ sở dữ liệu.

Cơ chế: Sử dụng Regex để phát hiện các từ khóa như UNION, OR 1=1, DROP TABLE trong input người dùng.

Chống XSS (Cross-Site Scripting)

Ngăn chặn việc chèn mã script độc hại vào trang web để đánh cắp session hoặc chuyển hướng người dùng.

Cơ chế: Lọc bỏ các thẻ <script>, các sự kiện onload, onerror và giao thức javascript:.

Chống LFI (Local File Inclusion)

Ngăn chặn truy cập trái phép vào các tệp tin hệ thống nhạy cảm trên máy chủ.

Cơ chế: Phát hiện các mẫu Path Traversal như ../, ..\ hoặc nỗ lực truy cập vào /etc/passwd.

Phòng thủ Nâng cao (Logic)

Các cơ chế bảo vệ thông minh dựa trên hành vi và ngữ cảnh.

  • Honeypot: Bẫy hacker truy cập link ẩn.
  • GeoIP: Chặn IP từ quốc gia không tin cậy.
  • Anti-CSRF: Kiểm tra nguồn gốc request (Referer/Origin).
